# Portfolio web — entrega del trabajo práctico

## Estructura
- `index.html`: página principal del portfolio.
- `css/styles.css`: estilos y diseño adaptable a celulares y computadoras.
- `js/main.js`: menú móvil, alternancia de tema claro/oscuro y año automático.
- `img/`: recursos gráficos.
- `proyectos/Aulify/`: código fuente del proyecto Aulify entregado para este trabajo.

## Publicación en GitHub Pages
1. Crear un repositorio público en GitHub.
2. Subir el contenido de esta carpeta (no solamente el ZIP).
3. Verificar que `index.html` quede en la raíz del repositorio.
4. En Settings > Pages, elegir Deploy from a branch, `main` y `/(root)`.
5. Guardar y esperar a que GitHub Pages publique el sitio.

## Importante sobre Aulify
Se conserva el código fuente recibido dentro de `proyectos/Aulify/`. GitHub Pages sirve contenido estático y no ejecuta PHP ni bases de datos. Por eso, la página de inicio puede mostrarse como contenido estático, pero las funciones que dependen del backend requieren un servidor compatible.
