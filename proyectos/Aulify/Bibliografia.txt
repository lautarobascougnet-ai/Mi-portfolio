BIBLIOGRAFÍA Y FUENTES DE AULIFY
Fecha de elaboración: 12-10-2026

1. ALCANCE DE ESTE REGISTRO
===========================

Este archivo reúne las fuentes utilizadas en las tareas documentadas en esta
conversación: apuntes, reservas, pagos simulados, chat, avisos de mensajes,
paginación, encabezado y explicación de tecnologías y funciones.

La revisión se basó en el código local, los archivos del proyecto, las pruebas
y las indicaciones e imágenes proporcionadas por el usuario.

No se realizaron búsquedas web ni se consultaron páginas de documentación externa
como investigación durante esas tareas. Por eso, los enlaces externos de este
archivo se identifican como referencias presentes en el proyecto, no como
páginas leídas para desarrollar estas funciones.

No existe en el contexto disponible un historial completo de navegación de las
etapas anteriores del proyecto. No se atribuyen consultas que no estén registradas.
Las explicaciones generales también se apoyaron en conocimientos previos del
asistente; no se puede asignar a esos conocimientos una página consultada concreta.

4. DEPENDENCIAS Y PROCEDENCIA DEL CÓDIGO DE TERCEROS
===================================================

composer.json
  Uso: comprobar que la API utiliza Slim y slim/psr7.

composer.lock
  Uso: referencia local de versiones y procedencia de paquetes PHP.
  Sus enlaces identifican el origen de dependencias; no prueban visitas web.

porteo/tools/package.json
  Uso: comprobar las dependencias directas de herramientas JavaScript:
  qrcode, Sharp, Playwright Core y jsQR.

porteo/tools/package-lock.json
  Referencia del proyecto para las versiones exactas de dependencias Node.
  No se presenta como una lectura exhaustiva de cada dependencia indirecta.

Frontend/js/vendor/qrcode.js
  Uso: verificar la biblioteca QR incorporada y su interfaz expuesta al navegador.
  El archivo incluye información de licencia de terceros.

No se considera código propio de Aulify al código distribuido por esas bibliotecas.
Las licencias y créditos completos corresponden a los archivos de cada paquete.
